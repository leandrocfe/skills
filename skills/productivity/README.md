# Productivity

Ferramentas gerais de workflow, não específicas de código.

- **[caveman](./caveman/SKILL.md)** — Modo de comunicação ultra-comprimido. Corta ~75% do uso de tokens dropando filler enquanto mantém precisão técnica completa.
- **[grill-me](./grill-me/SKILL.md)** — Seja sabatinado sem dó sobre um plano ou design até cada ramo da árvore de decisão estar resolvido.
- **[handoff](./handoff/SKILL.md)** — Compacta a conversa atual em um documento de handoff para outro agente continuar o trabalho.
- **[write-a-skill](./write-a-skill/SKILL.md)** — Cria novas skills com estrutura correta, progressive disclosure e recursos empacotados.
