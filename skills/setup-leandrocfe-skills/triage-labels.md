# Labels de Triagem

As skills falam em termos de cinco papéis canônicos de triagem. Este arquivo mapeia cada papel pra string de label efetivamente usada no Rastreador deste repo.

| Label em leandrocfe-skills | Label no nosso Rastreador | Significado                                  |
| -------------------------- | ------------------------- | -------------------------------------------- |
| `precisa-de-triagem`       | `precisa-de-triagem`      | Mantenedor precisa avaliar essa issue        |
| `precisa-de-info`          | `precisa-de-info`         | Esperando reporter dar mais informação       |
| `pronta-pra-agente`        | `pronta-pra-agente`       | Totalmente especificada, pronta pra agente AFK |
| `pronta-pra-humano`        | `pronta-pra-humano`       | Requer implementação por humano              |
| `wontfix`                  | `wontfix`                 | Não vai ser feita                            |

Quando uma skill menciona um papel (ex: "aplicar label AFK-ready"), use a string correspondente da coluna direita.

Edite a coluna direita pra casar com o vocabulário que você efetivamente usa.

## Categorias adicionais

Toda issue triada também recebe **1 categoria**:

| Label em leandrocfe-skills | Label no nosso Rastreador | Significado                  |
| -------------------------- | ------------------------- | ---------------------------- |
| `bug`                      | `bug`                     | Algo está quebrado           |
| `enhancement`              | `enhancement`             | Feature nova ou melhoria     |
